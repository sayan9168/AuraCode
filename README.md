# AuraCode

### An esoteric, aura-driven programming language

Poetic syntax · Custom parser · Stack-based virtual machine

[![Status](https://img.shields.io/badge/Status-Concept%20%2F%20Early-yellow)](#)
[![Type](https://img.shields.io/badge/Type-Esoteric%20Language-purple)](#)

> Designed to feel unique and artistic — a creative language experiment, not a production toolchain.

---

## Concept

AuraCode explores a more expressive / poetic programming aesthetic:

- Distinct syntax inspired by "aura" / mood-driven wording
- Custom lexer & parser
- Stack-based virtual machine for execution

Ideal for language-design practice, demos, and creative coding experiments.

---

## Status

Early / conceptual stage. Implementation details will grow as the language solidifies.
